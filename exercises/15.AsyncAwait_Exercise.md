# 📝 Exercise 15: Async / Await (`15.async-await.js`)

### Questions:
1. What does the `async` keyword actually do to a function?
2. What does the `await` keyword do inside an async function?
3. Where must the `await` keyword be used? (Can it be used in a normal function?)
4. How do we handle errors in Async/Await compared to Promises?
5. Why should we use `Promise.all()` even when working with `await`?

### Practice Task:
- Create a file named `solution15.js`.
- Write an async function `getWeather` that:
    - Waits for a simulated `fetch` (2 seconds) to get "Cloudy".
    - Logs the result.
    - Uses `try...catch` to handle any potential error.
- Create a "Quick Quiz" app simulator:
    - Create an async function `askQuestion`.
    - It should `await` a promise that resolves after 1 second with a question string.
    - Log the question.
- Write a performance test:
    - Create two independent async tasks (e.g., `loadUsers` and `loadSettings`).
    - Run them **Sequentially** using two awaits and time the result.
    - Run them **In Parallel** using `Promise.all` and time the result.
    - Log which one was faster.
