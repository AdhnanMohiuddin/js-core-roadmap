# 📝 Exercise 20: DOM Basics (`20.dom-basics.js`)

### Questions:
1. What does **DOM** stand for? (Think of the "Remote Control" analogy).
2. What is the difference between `innerText` and `innerHTML`?
3. Which method is most flexible for selecting elements using any CSS selector?
4. Why is `addEventListener` better than the old `onclick` attribute?
5. What are the three basic steps to add a new element to the page from JS?

### Practice Task:
- Use your existing `index.html` file.
- **The Color Picker**: Create a button that, when clicked, changes the background color of the body to a random color (Hint: `document.body.style.backgroundColor`).
- **The Echo Box**: Create an input field and a paragraph. 
    - Use the `input` event to make the paragraph update in real-time as you type. (Hint: `addEventListener('input', ...)`).
- **The To-Do Mini**: Create a small text input and an "Add" button. 
    - When the button is clicked, create a new `<li>` and append it to the `#item-list` ul.
- **The Remover**: Add a "Delete" button next to each new list item (This is a Hero-level challenge!).
