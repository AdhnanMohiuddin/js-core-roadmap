# 📝 Exercise 24: Modern Collections (`24.modern-collections.js`) 💎

### Questions:
1. What is the main difference between an **Array** and a **Set**?
2. How do you check if an item exists in a **Set**? (Hint: It's a 3-letter method).
3. Why is a **Map** considered "stronger" than a regular object?
4. What happens when you try to change a property of an object that has been **frozen** with `Object.freeze()`?

### Practice Task:
- Create a file named `solution24.js`.
- **1. The Unique Cleaner 🧹**: You have an array `['apple', 'banana', 'apple', 'orange', 'banana', 'grape']`. Use a **Set** to turn this into a unique list of fruits.
- **2. The Role Manager 🛡️**: Create three user objects. Use a **Map** to assign a different "Power Level" (Number) to each user object. Log the power level of the second user.
- **3. The Immutable Config 🧊**: Create a `settings` object with `theme: "dark"`. Freeze it. Try to change the theme to "light" and then log the object. Did it change?

### The Ultimate Final Challenge:
- Create a function `cleanRoom(items)` that takes an array of items (some appearing multiple times). 
- It should:
    1. Remove all duplicates.
    2. Sort them alphabetically.
    3. Put them into a **frozen** object.
- **Bonus**: Can you return a **Map** where the `Key` is the item name and the `Value` is the length of that name?
