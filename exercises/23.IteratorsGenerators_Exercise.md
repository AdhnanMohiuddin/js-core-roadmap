# 📝 Exercise 23: Iterators & Generators (`23.iterators-generators.js`) 🔄

### Questions:
1. In your own words, what is an **Iterator**?
2. What does the `yield` keyword do inside a generator function?
3. What are the two properties inside the object returned by `.next()`? (Hint: `{ value, ??? }`)
4. Why can you use a `while(true)` loop inside a generator without crashing the browser?

### Practice Task:
- Create a file named `solution23.js`.
- **1. The Even Number Gen 🔢**: Write a Generator function `evenGens(limit)` that yields only even numbers up to the limit.
    - Test it using a `for...of` loop.
- **2. The Custom Step 🚶**: Create an iterator (manual, not a generator) that returns numbers starting from 0 but jumps by 5 every time (0, 5, 10, 15...).
- **3. The Card Dealer 🃏**: Create a generator that yields "Ace", "King", "Queen", "Jack" one by one. Use it to "deal" two cards by calling `.next()` twice.

### The Boss Challenge:
- **The Paginator**: Imagine you have an array of 100 items. Create a Generator that yields "Pages" of 10 items at a time.
- Every time you call `.next()`, you should get an array of the next 10 items until the main array is empty.
