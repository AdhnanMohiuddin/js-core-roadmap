# 📝 Exercise 13: Asynchronous Basics (`13.async-basics.js`)

### Questions:
1. What is the main difference between **Synchronous** and **Asynchronous** code?
2. What does it mean when we say a task is **Blocking**?
3. What is the role of the **Event Loop** in JavaScript?
4. In `setTimeout(() => console.log("Hi"), 0)`, why might "Hi" log *after* other code even if the timer is 0?
5. Why are callbacks used for tasks like fetching data from an API?

### Practice Task:
- Create a file named `solution13.js`.
- Write a script that logs "Start", then uses `setTimeout` to log "Middle" after 1.5 seconds, and finally logs "End" (outside the timer). Observe the order of the logs.
- Create a function `simulateDownload` that takes a `fileName` and a `callback`. 
- Inside the function, log "Downloading [fileName]...", use `setTimeout` (2 seconds) to represent the download time, and then execute the callback with a message: "[fileName] downloaded successfully!".
- Use `setInterval` to log "Loading..." every 500ms, and use `setTimeout` to stop that interval after 3 seconds using `clearInterval`.
