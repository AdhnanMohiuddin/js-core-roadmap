# 📝 Exercise 16: JSON & Fetch API (`16.json-and-fetch.js`)

### Questions:
1. What does **JSON** stand for?
2. What is the main difference between a **JavaScript Object** and a **JSON String**?
3. Which method would you use to turn a list of data in your code into a format you can send to a server?
4. In `const data = await response.json()`, why do we need to use the `await` keyword twice? (Once for fetch and once for .json())
5. How can you handle a scenario where a URL for an API is incorrect or the server is down?

### Practice Task:
- Create a file named `solution16.js`.
- Create a simple object `movie` with keys like `title`, `year`, and `rating`. 
- Convert it into a JSON string and log it.
- Convert that string back into an object and update the `rating`.
- **The Mini-Project**: Use the free "PokeAPI" (`https://pokeapi.co/api/v2/pokemon/pikachu`) to:
    - `fetch` the data for Pikachu.
    - Log the Pokemon's `name` and its `base_experience`.
    - Wrap the whole process in a `try...catch` block to handle errors.
- **The Challenge**: Fetch a list of "Todos" from `https://jsonplaceholder.typicode.com/todos` and only log the titles of the first 5 items. (Hint: Use `.slice(0, 5)` and `.forEach`).
