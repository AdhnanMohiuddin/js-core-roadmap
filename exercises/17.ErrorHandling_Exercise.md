# 📝 Exercise 17: Error Handling & Debugging (`17.error-handling.js`)

### Questions:
1. What is the role of the `catch` block?
2. When should you use the `finally` block?
3. What is the difference between an error that happens "Naturally" (like a typo) and a "Thrown" error (using `throw`)?
4. What is **Error Bubbling** (Propagation)? 
5. Why would you want to use the `new Error()` object instead of just throwing a string like `throw "Problem"`?

### Practice Task:
- Create a file named `solution17.js`.
- **The Input Validator**: Write a function `checkPassword` that takes a password. 
    - If it's shorter than 8 characters, `throw` a custom error: "Password too weak! 🔒".
    - Wrap the call in a `try...catch` block to log the error message.
- **The Dangerous Math**: Create a function that divides two numbers. 
    - Throw an error if the user tries to divide by zero.
    - Use `finally` to log "Calculation Complete" no matter what.
- **The Retry Challenge**: Create a function `unreliableNetwork` that has a 50% chance of failing (use `Math.random() > 0.5`).
    - Use a `try...catch` block with a simple loop to "Try again" if the first one fails.
    - If it fails 3 times in a row, give up and log "Server unreachable".
