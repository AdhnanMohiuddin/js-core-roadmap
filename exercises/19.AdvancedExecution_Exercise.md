# 📝 Exercise 19: Advanced Execution & Prototypes (`19.advanced-execution.js`)

### Questions:
1. What is a **Prototype** in your own words? (Use the "DNA" analogy).
2. What is the **Prototype Chain** and where does it end?
3. In JS, are **Classes** different from Prototypal Inheritance under the hood?
4. What is the main difference between a **Microtask** and a **Macrotask**?
5. Why does `Promise.resolve().then(...)` run before `setTimeout(...)`?

### Practice Task:
- Create a file named `solution19.js`.
- **The DNA Challenge (Old School)**: Create a constructor function `Laptop` that takes a `brand`. 
    - Use the prototype to add a method `turnOn` that logs "Personal ${brand} is starting...".
    - Create two laptops and call `turnOn` for both.
- **The Modern Challenge (Classes)**: Convert that `Laptop` function into a modern `class`. 
    - Add a method `writeCode` that uses a property.
- **The Race Challenge**: Write a script that logs "Start", then uses `setTimeout` (0ms), then a `Promise` (resolve), and finally logs "End". 
    - Before running it, predict the exact order of the 4 logs. (Hint: Micro vs Macro).
- **The Inspection**: Create an object and use `Object.getPrototypeOf()` to see its "Grandfather" prototype in the console.
