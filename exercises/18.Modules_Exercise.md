# 📝 Exercise 18: ES Modules (`18.modules.js`)

### Questions:
1. Why must we use `type="module"` in our HTML script tag?
2. What is the main difference between a **Named Export** and a **Default Export**?
3. How many Default Exports can you have in a single file?
4. When should you use the `as` keyword during an import?
5. Why is it important to include the `.js` extension at the end of the file path when importing in a browser environment?

### Practice Task:
- Create two files: `mathUtils.js` and `main.js`.
- In `mathUtils.js`:
    - **Export** a constant PI with the value `3.14159`.
    - **Export** a function `calculateArea` that takes a radius.
    - **Default Export** an object named `calculator` with a type like "Premium".
- In `main.js`:
    - **Import** PI and calculateArea.
    - **Import** the default calculator object and rename it to `myCalculator`.
    - Log all three to your console.
- **The Challenge**: If you had another file with another `PI` constant, how would you import both without causing an error? (Hint: Use `as`).
