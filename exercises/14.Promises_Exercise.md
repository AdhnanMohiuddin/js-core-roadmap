# 📝 Exercise 14: Promises (`14.promises.js`)

### Questions:
1. What are the three possible **states** of a Promise?
2. What is the purpose of the `resolve` and `reject` functions?
3. Which method is used to handle a **rejected** promise?
4. How does **Promise Chaining** solve the "Callback Hell" problem?
5. What is the difference between `Promise.all()` and `Promise.race()`?

### Practice Task:
- Create a file named `solution14.js`.
- Create a function `checkStock` that returns a Promise. 
    - If `inStock` is true, resolve with "Item is available".
    - If `inStock` is false, reject with "Out of stock".
- Handle the promise using `.then()`, `.catch()`, and `.finally()`.
- Create three separate promises that resolve after 1, 2, and 3 seconds respectively. Use `Promise.all()` to log an array of all results once they are all finished.
- Create two promises, one that resolves in 500ms and one in 1000ms. Use `Promise.race()` to log only the "winner".
