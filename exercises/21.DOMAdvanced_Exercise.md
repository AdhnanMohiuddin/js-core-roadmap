# 📝 Exercise 21: DOM Advanced (`21.dom-advanced.html`)

### Questions:
1. What is the difference between `querySelector` and `querySelectorAll`?
2. What is a **NodeList** and should you treat it exactly like an Array? (Hint: You can .forEach, but you can't .map directly).
3. In `window.scrollTo`, what is the purpose of the `behavior: 'smooth'` property?
4. What is the difference between `localStorage.setItem()` and `localStorage.getItem()`?
5. How long does data stay in **Local Storage**? (Until the session ends, or until you manually clear it?)

### Practice Task:
- Create a simple To-Do application. 
- **Step 1**: Use `querySelectorAll` to count how many `.list-item` elements are currently on the page.
- **Step 2**: Use `localStorage` to save the value of an input every time the user types. (Hint: Use the `input` event).
- **Step 3**: Use `window.scrollTo()` to make a "Return to Top" button that smoothly scrolls to the top of the dashboard.
- **The Challenge**: If you have a list of themes (Light, Dark, Neon), create 3 buttons that change the `localStorage` key 'theme' and then update the background color based on that theme. Refresh the page to see if your theme is still active!
