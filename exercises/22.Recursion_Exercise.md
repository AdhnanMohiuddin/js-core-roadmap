# 📝 Exercise 22: Recursion (`22.recursion.js`) 🌀

### Questions:
1. What is the difference between a **Base Case** and a **Recursive Step**?
2. What happens if you forget to write a Base Case? (Think "Stack Overflow").
3. Why is recursion often described as "Opening Russian Nesting Dolls"?
4. How is the **Call Stack** affected when a function calls itself?

### Practice Task:
- Create a file named `solution22.js`.
- **1. The Reverse String ⏪**: Write a recursive function `reverse` that reverses a string (e.g. "Adnan" -> "nandA").
    - **Base Case**: If the string is empty, return "".
    - **Recursive Step**: Return the last character + `reverse` of the remaining string.
    - **The Goal**: Reverse your own name using recursion!
- **2. The Power Function ⚡**: Create a function `power(base, exponent)` recursively. (e.g. 2^3 = 2 * 2 * 2 = 8).
    - **Base Case**: If the exponent is 0, return 1.
    - **Goal**: Calculate `2 to the power of 10` using your own recursive function.
- **3. The Deep Explorer 📂**: Create a nested object `folderStructure` that represents folders within folders.
    - Write a function that recursively logs the name of every folder, no matter how deep they are!
    - **Base Case**: If a folder has no more child folders, STOP.

### The Boss Challenge:
- Write a recursive function `fibonacci(n)` that returns the Nth number in the sequence (0, 1, 1, 2, 3, 5, 8...). 
- Warning: Fibonacci is computationally heavy—can you explain *why* every time you call it, it creates a "Tree" of calls?
